Privacy

JSON Mate 隐私说明

JSON Mate 用于查看、编辑和转换 JSON 数据。扩展会在本地读取当前页面中的 JSON 内容来完成渲染和工具操作，但不会把 JSON 内容上传到 JSON Mate 的遥测服务。

匿名使用统计

匿名使用统计默认开启，可在扩展设置页关闭。统计用于了解活跃安装量、版本分布和核心功能入口使用情况。

会发送的信息：

  • 匿名安装 ID随机生成，仅用于区分安装，不包含账号或设备身份。
  • 扩展版本例如 0.2.4，用于判断版本分布。
  • 事件类型install、update、daily_active、viewer_open、toolkit_open。
  • 粗粒度环境扩展语言、浏览器大类、操作系统大类。
  • 日期按 UTC 日期聚合，客户端会限频发送。

不会发送的信息：

  • JSON 内容不会上传页面 JSON、API 响应体或用户粘贴文本。
  • 页面信息不会上传页面 URL、域名、路径或查询参数。
  • 操作内容不会上传 JSON path、搜索词、转换输入或转换输出。

关闭方式

打开 JSON Mate 设置页，关闭 “Share anonymous usage statistics / 发送匿名使用统计”。关闭后扩展不会继续发送遥测请求，并会清理本地遥测 ID 与发送记录。

Chrome Web Store User Data Policy

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.
