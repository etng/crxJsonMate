JSON 页面不要再靠裸文本硬看。

JSON Mate 把页面识别、树形浏览、局部编辑、路径复制、图片预览和文本转换放到同一个工作区里。适合每天调接口、查 payload、看日志的人。

Built for real debugging

从“能格式化”到“能干活”。

普通 JSON viewer 只解决缩进。JSON Mate 更关注调试时反复发生的动作：定位一个字段、复制路径、判断值类型、把时间戳转成人话、把 URL decode 后再回填。

01

Viewer workspace

树和右侧工具面板并排工作。选中节点后直接编辑值、复制 path、打开 URL、预览图片，面板宽度也可以按屏幕拖动。

02

Quick tools

常见转换不再跳出上下文。URL、Base64、Unicode、HTML、大小写等工具可以直接处理当前值并回写。

03

Launcher library

点击扩展图标先看到输入框，再看到最近打开和收藏集合。适合把常用 JSON endpoint 当工具入口管理。

04

Syntax-aware editing

JSON 高亮尊重字符串边界，不会把引号里的数字拆出来乱上色。编辑区和工具弹窗使用同一套高亮规则。

Workflow

一个接口响应，几秒内变成可操作结构。

  1. Open JSON URL 自动识别页面中的 JSON，不需要复制到第三方网站。
  2. Select value 树上定位字段，右侧看到路径、key、原始值和可用工具。
  3. Transform or save 转换当前值、打开嵌套 JSON、保存到收藏，或继续在 launcher 里管理。

Install

先从 GitHub Release 用起来。

  • 1. Download 下载最新的 json-mate-vX.Y.Z.zip。
  • 2. Load unpacked 解压后在 Chrome extensions 页面加载目录。
  • 3. Pin and inspect 固定图标，打开任意 JSON URL 或直接进入 launcher。
